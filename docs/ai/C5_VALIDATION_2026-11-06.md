## Границы приёмки

Не объявляются проверенными UI/пакеты двумя клиентами, физическое исчезновение вещи
из открытого окна инвентаря и совместный проход C1–C5. Нет испытания crash в точной
точке сетевого неопределённого commit; квитанция и консервативный write fence для
этого предусмотрены, но это не результат проведённого fault injection.

Тестируются обычные реальные предметы и мгновенные зелья, не вся номенклатура Aion.
Live обмен без выхода, частичные стеки, bind confirmation, stigma, истекающие,
упакованные и неторгуемые вещи исключены явно. Проверка всех видов камней и
косметических свойств клиентом остаётся в матрице C8. Передача не создаёт новый
item ID и не переносит строки камней на другой ID.

Флаг по умолчанию выключен. Для общего игрового прохода: включить C5 в отдельной
установке после SQL → items list → native equip/unequip → give → выход/вход →
use → take → выход/вход → restart → сверка количества, ID и квитанций.
