# C7: занятия и подсказки компаньона

Дата: 2026-11-06. База: C6 `9001c3b90`. Следом — C8, не Living World/LLM.

## Поведение

`//companion activities` показывает занятия и доступность проверенных заданий.
`//companion activity escort` отключает помощь и включает следование;
`support` включает следование и ранее проверенную помощь/лечение;
`rest` останавливает движение, помощь и незавершённые боевые действия.
`//companion activity quest 1102|1120` сохраняет выбранное намерение после проверки
доступности и неизменности native данных. Ошибка сохранения не заменяет прежний выбор.
Эта команда сама не принимает задание и не включает помощь в бою.
`//companion next` объясняет ближайший шаг: принять, выполнить цель, сдать или выбрать
следующее задание. Координаты — ориентир; построенного дальнего маршрута они не обещают.
Приём и сдача, выбор награды остаются действиями владельца.

Выбранный квест сохраняется прежним C2 intent. Нативный журнал владельца — единственный
источник прогресса. Смена follow/assist/stay не удаляет выбранный квест; `goal clear`
удаляет только AI intent. Бой/следование после restart требуют явного summon и управления.
Клиентское окно не добавлено: доступный интерфейс этого этапа — игровые команды.

## Ограниченная вторая цель

1120 (Thinning out Worgs), Поэта 210010000, min level 6, native MonsterHunt,
один var0, 9 убийств, NPC 203082, цели 210142/210143. Зафиксированы **11** статичных
точек; random-walk/walker/event/temporary исключены. Планы сравнивают весь набор
статичных спавнов, счётчик, prerequisites, targets и NPC с утверждённым manifest.
Оригинальный 1102 остаётся 3 убийства/39 точек/NPC 203057/prerequisite 1101.
1120 не открывает все задания или всех монстров. 1112 имеет несколько счётчиков;
1113 не прошёл текущие требования метаданных всех target spawns — они не включены.

Quest execution/combat allowlist допускает только уникальное подмножество `1102,1120`;
goal и execution списки должны совпадать. Неизвестное ID, дубли и неверный формат
выключают разрешение. Авторизация каждого удара повторно проверяет текущий allowlist,
native START/var0, владельца/сессию/мир, видимость, дистанцию и точку появления.
Старые accepted ADR и validation logs сохраняют исторический exact-1102 контракт.
Один source-boundary тест обновлён на curated allowlist; прежняя точность 1102 проверяется.

## Включение и откат

Все новые функции по умолчанию выключены. `ai.companions.activities.enabled=true`
включает команды каталога. Для второй цели явно установить оба существующих списка
`ai.companions.quest_goals.allowed_quest_ids=1102,1120` и
`ai.companions.quest_execution.allowed_quest_ids=1102,1120`, сохранив остальные C1–C4 gates.
Каталог не включает эти flags автоматически.

Отключение каталога закрывает новые команды, но не прежние today/goal/assist.
Для прекращения исполнения отключить quest_execution/его combat или убрать 1120
из обоих списков. Проверка перед ударом немедленно отзывает разрешение; journal и
intent не удаляются. Полный `ai.companions.enabled=false` запускает штатный cleanup.
Конфиги читаются при запуске; runtime rollback тесты меняют поля конфигурации внутри
тестового JVM, отдельного live reload UI этот этап не создаёт.
